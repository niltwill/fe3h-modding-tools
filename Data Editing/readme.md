# Data tools

This is where I'll put some useful Python tools that handle some data stuff with Python scripts. Usually the 010 templates are better to use, as you can choose from enum values easily.

* mapScriptData_bsi.py
* mapSpawnData_bai.py
* monasterySpawnData_bai.py
* vmes_param.py

These ones exist so that the BAI and BSI files can be edited more easily, without needing to use the Triabolical editor (which is good for an overview, but not for quick search & find or replace operations). Not to mention it doesn't support the monastery BAI at all (yet).
